## 项目概况

璞荟铭庭为杭州滨江区的人才共有产权保障住房项目，开发建设单位为杭州滨江城建发展有限公司。2024 年公开配售涉及 1#、2#、3#、4# 楼，共 368 套，房源为 65、89㎡，毛坯交付。[S2] [S3] [S4]

项目位于诚业南路西侧、创智街北侧。杭州市民政局地名公告将北界描述为仁荣街，西邻浦乐单元 R21-21a 地块保障性住房项目（公共租赁房）。房产介绍页仍有“北至规划彩霞路、西至火炬大道规划绿化”等表述；此处保留两种来源的用词，不将它们直接视为同一地块边界。[S1] [S4] [S5]

## 资料差异与采用原则

1. **地名公告的政区字段**：S1 第 3 项“璞荟铭庭”的“所在政区”原文为“拱墅区”，但位置描述是诚业南路、创智街、仁荣街和浦乐单元；S3 项目配售信息以及 S5、S6 均指向滨江区。本目录按配售项目资料描述为滨江区，同时如实保留该冲突，不自行修改或宣称官方已更正原文。
2. **道路与西侧边界**：S1 写“北至仁荣街、西至浦乐单元 R21-21a 地块保障性住房项目”；S4、S5 写“北至规划彩霞路、西至火炬大道规划绿化”。现有文字不能证明道路更名关系或各页面地块统计范围，故不自行合并为精确四至。
3. **建筑面积**：S4 为 54,721㎡，S5 为 54,635㎡；S6 为 194,145㎡，且占地面积也与前两者不同。无法确认统计范围与版本，首页不使用这些面积数字。S4、S5 占地面积同为 13,476㎡，但仍不将它当作测绘结论。
4. **证照日期**：S2 表述为 2024-09-05 取得预售许可证，S5 列发证时间为 2024-09-02。本目录仅采用双方一致的证号，不将两种日期合并成一个确定日期。
5. **销售、物业和交付状态**：网页可出现“在售 / 售完 / 待售”等不同标签，物业公司、交付时间也可能滞后。本项目不据此断言当前状态，不把规划配套、学区或平台宣传当作交付承诺。

楼栋层数、容积率和绿化率目前来自房产平台，证据层级与地名 / 公证公告不同，表格已分别标明。价格、物业费、入学和申购资格等以主管部门、开发建设单位或正式合同的适用文件为准。

## 与本仓库模型的关系

- 本仓库复原的是用户照片中的 **89-A 户型**，没有复原所有 65 / 89㎡ 户型。
- 阳台南偏西 10°、默认所在 18 层来自用户设定；层高、默认透明楼栋总层数与邻户内部为模型参数。
- 资料中的 21—25 层不代表模型已按真实楼栋逐栋建模；本次资料整理没有修改网页几何、光照或楼层参数。
- 原图实黑墙段为图纸标记的转录，结构判断须查正式结构图。
