## 使用

下载 `docs/index.html`，直接在支持 WebGL 的浏览器打开。手机微信建议点击在线浏览链接。可切换三维、平面、室内；拖动转向、双指缩放，室内使用方向按钮或电脑 WASD / 方向键移动。右上角设置可修改各房间三类表面的颜色和材质、门的开关、FOV、眼高、灯光和楼层。

清晨、正午、黄昏、夜晚采用杭州和阳台南偏西 10° 的太阳方向。默认所在楼层 18 层、层高 3m；透明楼栋默认 26 层，可调整。“整栋建筑”查看整体，“重置视角”返回户型。

## 构建与维护

Python 3.10+ 构建无需额外依赖：

```sh
python src/build_house.py
python -m http.server 8879 --directory docs
```

访问 `http://localhost:8879/`。重新计算光照或生成平面图先安装 `pip install -r requirements.txt`。平面图字体默认使用 Windows 微软雅黑；其他系统需将 `HOUSE_FONT` 设置为支持中文的 TTF/TTC 文件。

几何变化时，在已启动网页的开发者工具导出 `JSON.stringify(houseBakeSource())` 至 `src/bake-source.json`，依次运行：

```sh
python src/bake_lighting.py
python src/bake_sun.py
python src/build_house.py
```

更改太阳参考日期或朝向时先修改并运行 `src/make_solar.py`，再重算太阳光照。

## 发布

GitHub Pages 从 `main` 分支的 `/docs` 目录发布。修改后构建、提交并推送即可更新。运行时没有 CDN、在线字体、远程贴图或打包服务依赖。云同步未配置时不产生云请求；用户启用账号同步后通过 HTTPS 连接自己的 Supabase 项目。第三方库授权见 `licenses/THIRD_PARTY.md`。

## V14 渲染品质与储物细节

新增`src/render-quality.js`，由构建脚本内嵌到单HTML；设置→渲染品质提供自动、精细、均衡、轻量，并沿用本地/可选云同步。桌面自动精细，手机/微信自动均衡；缺WebGL深度或半浮点扩展分别回退遮蔽/反射功能。采用分房间实际场景cubemap与PMREM、边界盒反射修正、深度接触遮蔽及双边滤波；保留FXAA、现有219张烘焙光照。颜色转线性、数据纹理与颜色贴图区分。没有恢复路径追踪，也没有外部贴图请求。

环境周边改为住宅高层的示意比例，细化立面、阳台和零散夜间亮窗，改善天空云/雾层次。家具圆角、法线和粗糙度细化。环境反射仅补高光，不能再次叠加烘焙漫反射。透明玻璃在RGBE目标混合会破坏指数，反射采样应使用线性half-float或线性RGBA8；相机far须覆盖天空。

储物间北、东、南三面墙设置348零件六层架，层板18mm、柱24mm、高2.46m，中央约0.655m通道；阳台洗烘柜贴东墙、前面朝西。A总计766部件、109合并mesh、33家具诊断条目。墙线/门洞不变，建筑烘焙快照不变，不需要重烘焙。

验证入口：`validation/verify-decor-preset.cjs`、`validation/verify-render-quality.cjs`，通过环境变量`PLAYWRIGHT_MODULE`指向已安装的Playwright包，`CHROME_PATH`可覆盖Chrome位置。需在项目目录启动8879端口HTTP服务。结果和实际画布截图在validation/v14-*，9张家装图更新到assets。

精细档仍是面向自由漫游的实时近似：AO看不到画面外遮挡；反射按房间缓存，非实时平面镜；家具尚未参与完整间接光烘焙，变化材质不会重算全局颜色串染。环境是示意内容。没有真机微信帧率与视觉质量结论。
