## VIS-01 · P1 · 室内开灯过亮，浅色材质层次被压缩

- 状态：已复现；用户也已反馈
- 复现：家装 A → 室内 → 夜晚或正午 → 顶灯开启，亮度保持默认 100%；查看卫生间、厨房和主卧。
- 现象：卫生间墙砖、台盆与马桶趋于同一浅白色，砖缝和陶瓷轮廓变淡；厨房吊柜、台面和地面出现大片高亮。桌面、手机 Chrome 和 Windows WebKit 均可复现。
- 证据与边界：固定中央区域（横向15–85%、纵向10–80%）中，手机卫生间夜晚开灯 RGB 三通道均≥235 的像素占49.6%，亮度中位数约242/255；厨房正午开灯约10.8%的像素三通道均≥250。该统计包含浅色材料和灯具，不是照度测量或独立的曝光合格标准。
- 待排查方向：需共同核对烘焙灯能量、运行时灯强/间接光缩放、曝光与色调映射。仅凭当前截图不能断言是重复加光。

## VIS-02 · P2 · 白天关灯时，墙面与天花板出现斑驳暗块

- 状态：桌面和手机均已复现
- 复现：家装 A → 室内 → 正午 → 关闭顶灯；查看客餐厅、主次卧与卫生间。
- 现象：墙顶出现云团状明暗与脏污感，部分房间边角有明显黑边；床面和沙发也有尺度偏大的暗块。光照诊断为 matched fixed state，表明截图已等待静态照明完成，不是未加载贴图的占位画面。
- 证据与边界：与开灯状态相比，暗块在自然光下更突出。可见图案不足以单独区分材质纹理、烘焙噪声、图集采样或间接光因素。
- 待排查方向：后续需分离检查静态灯图、表面PBR、AO和纹理采样；本轮只记录现象。

## VIS-03 · P2 · 陶瓷与硬质模型近景有不自然的折面和放射状阴影

- 状态：已复现；网格闭合测试仍通过
- 复现：家装 A → 阳台洗漱柜与卫生间 → 正午关灯 → 近距离查看台盆、马桶圈。
- 现象：阳台一体台盆的盆沿和四角呈明显三角收缩折痕；卫生间盆体与马桶圈出现放射状皱褶/明暗条纹。硬质陶瓷看起来像软质折叠材料。
- 证据与边界：high/mobile两档660份实体部件的开放边、非流形边、退化面、绕序和反向法线计数均为0；这些检查不证明高光法线或曲面造型正确。
- 待排查方向：模型生成的 finish() 对所有面启用平滑法线，且部分盆体缺少针对硬面/曲面的法线分离；这是排查方向，尚未通过消融实验确认根因。

## VIS-04 · P2 · 改动一扇门会让其他房间整体切换光照外观

- 状态：已复现；属于现有回退策略的视觉不连续
- 复现：家装 A → 主卧 → 夜晚开灯100%，记录画面；在设置中切换书房门开关，再看主卧。
- 现象：主卧墙面、窗帘、床品和反射整体变暗/变平。静态照明从 matched fixed state 切为 door configuration changed，恢复旧光照。
- 证据与边界：同机位中央区域平均亮度：桌面189.8→143.1/255，手机196.8→141.2/255。改变书房门也影响主卧；这是稳态前后比较，不是只持续一帧的闪烁。
- 待排查方向：现有策略为避免使用过期门遮挡而全局禁用静态照明；属于可解释的实现限制，但用户体验上存在明显跳变。后续需评估局部回退或两条路径的视觉匹配。
